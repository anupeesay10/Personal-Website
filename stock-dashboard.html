Stock Dashboard

Real-time stock data visualization.

Project Overview

Note: This application is hosted on Render’s free tier, so the initial load may take a moment if the server is spinning up. Once loaded, performance should be noticeably faster on subsequent visits.

This is a dashboard that displays four charts given a stock ticker of your choice: candlestick, trading volume, daily returns, and drawdowns. You can choose between "All Years Statistics", or "Yearly Statistics" for a specific year. This dashboard uses the Yahoo Finance (yfinance) library in python to fetch stock data, and PostgreSQL to store the data.

The data logic is as follows:

  1. A user enters a stock ticker symbol.
  2. If the data for that given stock is currently in the PostgreSQL database, it fetches the data from there.
  3. Otherwise, it makes an API call to Yahoo Finance to get the data.
  4. The data is then stored in the PostgreSQL database for future use.
  5. Finally, the data is displayed on the dashboard.

Essentially, this mechanism ensures that the data is fetched only when necessary, reducing unnecessary API calls and improving performance.
